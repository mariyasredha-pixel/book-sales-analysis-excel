# 📚 Book Sales Analysis Dashboard – Microsoft Excel

An interactive Excel dashboard developed to analyze book sales performance, publisher revenue, unit sales, ratings, genres, languages, authors, and publishing-year trends. The dashboard uses Pivot Tables, charts, and interactive filters to present sales data in a clear and visual format.

---

## 📊 Dashboard Overview

The dashboard provides an overview of book sales performance through key metrics, charts, and summary tables.

### Key Performance Indicators (KPIs)

- **Total Books:** 1986.6K (as displayed on the dashboard)
- **Total Publisher Revenue:** 902.31M
- **Total Units Sold:** 10354.4K
- **Average Rating:** 4.3K (as displayed on the dashboard)

---

## 📈 Key Dashboard Visualizations

- **Language-Wise Sales:** Analyzes gross sales across different language codes.
- **Genre-Wise Sales:** Visualizes sales distribution across genres, including fiction, nonfiction, and genre fiction.
- **Year-Wise Sales:** Displays sales trends across publishing years.
- **Author Rating–Sales Analysis:** Explores sales based on author rating categories such as Excellent, Famous, Intermediate, and Novice.
- **Genre-Wise Sales and Ratings:** Compares sales and ratings across different book genres.
- **Top 5 Publishers by Revenue:** Highlights leading publishers based on publisher revenue.
- **Top 4 Books by Sales:** Compares sales of *When You Are Engulfed in Flames*, *Go Set a Watchman*, *Daughter of Smoke & Bone*, and *Beowulf*.
